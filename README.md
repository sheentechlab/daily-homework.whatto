# 文言词语小练习

基于 React、TypeScript 和 Vite 的前端练习应用。初始包含四篇课文的词语题库，并支持在浏览器本地导入新的 PDF 题目。

## 本地运行

需要 Node.js 22.13 或更新版本。

```bash
npm install
npm run dev
```

## 生产构建

```bash
npm run build
npm run preview
```

构建产物位于 `dist/`，可以部署到支持静态站点的托管服务或自己的域名。域名指向站点根目录时无需额外路由配置。

## PDF 导入说明

- PDF 在浏览器中由 PDF.js 解析，不会上传到应用服务器。
- 文件限制为 20 MB；目前提取 PDF 的文字层，不含 OCR。图片扫描件如果没有文字层，页面会提示无法识别。
- 题目解析后需要检查词语并补上正确释义。原始填空卷没有答案，因此应用不会猜测并保存释义。
- 自定义课文保存在当前浏览器的 `localStorage` 中，只在当前浏览器和设备可见。清理浏览器站点数据会移除这些课文。

## 部署提示

这是纯前端项目，不需要 API 服务器。`npm run build` 后将 `dist/` 内容发布到静态 Web 服务即可。若部署在域名的子路径下，需要在 `vite.config.ts` 中设置对应的 `base`。
